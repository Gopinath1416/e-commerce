# GadgetZone - React E-commerce Website

## Overview

GadgetZone is a responsive e-commerce web application developed using React.js. It allows users to browse products, search, filter by category, manage a shopping cart, and complete a simple checkout process.

## Features

- Responsive Home Page
- Product Listing
- Product Details
- Search Products
- Category Filter
- Product Sorting
- Shopping Cart
- Login & Registration
- About Page
- Contact Page

## Technologies Used

- React.js
- React Router
- Context API
- React Bootstrap
- HTML
- CSS
- JavaScript

## Installation

```bash
npm install
npm start
```
